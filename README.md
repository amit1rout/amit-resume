# Amit Rout — Portfolio

A responsive, static portfolio for GitHub Pages. No build process or dependencies are required.

## Publish on GitHub Pages

1. Create a GitHub repository, or use your existing portfolio repository.
2. Upload `index.html`, `styles.css`, `favicon.svg`, and `.nojekyll` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, and save.
5. GitHub Pages will display the published URL once deployment finishes.

For a personal site at `https://YOUR-USERNAME.github.io`, name the repository `YOUR-USERNAME.github.io`. Other repository names produce a project URL.

## Edit

- Content and links: `index.html`
- Colors, typography and responsive layout: `styles.css`
- Browser icon: `favicon.svg`

The website uses Google Fonts with local system-font fallbacks. It has no analytics, cookies, or contact form. Gmail and LinkedIn are the contact destinations.
